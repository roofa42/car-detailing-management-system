# نظام لمعة لإدارة محل العناية بالسيارات

نظام عربي RTL لإدارة محلات الغسيل والتنظيف والتلميع وتصحيح الطلاء وحماية السيارات.

## التشغيل

```bash
npm install
cp .env.example .env
npm start
```

يتطلب التشغيل مع التخزين الدائم MongoDB محليًا أو رابط MongoDB في `MONGODB_URI`.

## ما تم إنجازه

- خادم Express متصل اختياريًا بـ MongoDB.
- نماذج مترابطة للزبائن والسيارات والخدمات والمنتجات وأوامر العمل والمدفوعات والمصاريف.
- واجهات API فعلية للزبائن والسيارات والخدمات وأوامر العمل والمدفوعات والمصاريف ولوحة المؤشرات.
- الأرشفة الآمنة بدل الحذف النهائي للزبائن والخدمات.
- احتساب مؤشرات اليوم من المدفوعات والمصاريف وأوامر العمل.
- واجهة عربية RTL متجاوبة دون بيانات تجريبية ثابتة.

## أمثلة API

- `GET/POST /api/customers`
- `GET/POST /api/cars`
- `GET/POST /api/services`
- `GET/POST /api/work-orders`
- `POST /api/payments`
- `POST /api/expenses`
- `GET /api/dashboard`
