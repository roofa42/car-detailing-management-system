# نظام لمعة لإدارة محل العناية بالسيارات

نظام عربي RTL لإدارة محلات الغسيل والتنظيف والتلميع وتصحيح الطلاء وحماية السيارات.

## التشغيل

```bash
npm install
npm start
```

ثم افتح `http://localhost:3000`.

## الحالة الحالية

تم إنشاء الهيكل الأولي القابل للتشغيل، ويشمل:

- خادم Express ونقطة فحص الصحة `/api/health`.
- واجهة عربية RTL متجاوبة.
- لوحة تحكم أولية وحالات فارغة واضحة.
- شاشة استقبال سيارة، وقسم الزبائن، ومخطط أوامر العمل.
- إعدادات بيئة منفصلة وقابلية ربط MongoDB.

## خارطة التنفيذ

1. نماذج قاعدة البيانات والعلاقات.
2. واجهات API للمصادقة والزبائن والسيارات وأوامر العمل.
3. الخدمات والمخزون والمشتريات والحسابات والفواتير.
4. رفع الصور، التقارير، النسخ الاحتياطي، والصلاحيات.
5. الاختبارات والتدقيق الأمني وتجهيز الإنتاج.

لا توجد بيانات تجريبية ثابتة في الواجهة؛ ستبقى الإحصائيات فارغة إلى حين إدخال بيانات حقيقية.
